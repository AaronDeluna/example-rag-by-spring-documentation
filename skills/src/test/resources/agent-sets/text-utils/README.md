# Набор text-utils

Набор простых текстовых утилит для проверки работы agent-runner с разными наборами.

Содержит:

- `reverse-text` — переворачивает строку посимвольно.
- `word-count` — считает количество слов в строке.

Используется в `AgentWorkspacePreparerTests` для проверки, что переключение между наборами `default` и `text-utils` корректно обновляет содержимое workspace.
