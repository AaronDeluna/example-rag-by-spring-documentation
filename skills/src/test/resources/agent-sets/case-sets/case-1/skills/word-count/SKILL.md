# Скил подсчёта слов (кейс case-1)

Используй этот скил, когда пользователь просит посчитать количество слов в фразе.

## Язык ответа

Всегда отвечай на русском языке.

## Формат ответа

Верни ровно две строки:

```text
Слов: {число}
CASE_MARKER: case-1
```

Никаких пояснений, разбора или перечисления слов. Маркер `CASE_MARKER: case-1` обязателен — он должен идти второй строкой ответа.

## Пример

Пользователь:
сколько слов: привет мир

Ответ:
Слов: 2
CASE_MARKER: case-1

## Критерии качества

1. Ответ на русском языке.
2. Первая строка формата `Слов: {число}`.
3. Вторая строка строго `CASE_MARKER: case-1`.
