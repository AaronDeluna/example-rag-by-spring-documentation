# Настройка Checkstyle в Maven-проекте

Следуйте строго по шагам. При любой ошибке останавливайтесь и сообщайте причину.

---

## Шаг 1. Проверка наличия `pom.xml`

- Убедитесь, что в текущем каталоге есть файл `pom.xml`.
- **Если отсутствует** – остановитесь с сообщением: «Не найден pom.xml. Выполните скилл в корне Maven-проекта.»

---

## Шаг 2. Проверка наличия плагина Checkstyle

- Прочитайте `pom.xml`. Найдите секцию `<build><plugins>`.
- Проверьте, присутствует ли плагин с `groupId=org.apache.maven.plugins` и `artifactId=maven-checkstyle-plugin`.
- **Если плагин уже есть** – перейдите к Шагу 4.
- **Если нет** – выполните Шаг 3.

---

## Шаг 3. Добавление плагина в `pom.xml`

Добавьте в секцию `<build><plugins>` блок (если секции нет – создайте) из файла в корне скилла `assets/additional-block-to-pom.xml`.

Сохраните `pom.xml`. При ошибке – остановитесь.

---

## Шаг 4. Проверка наличия файла конфигурации `checkstyle.xml`

- В корне проекта (там же, где `pom.xml`) проверьте наличие файла `checkstyle.xml`.
- **Если существует** – перейдите к Шагу 6.
- **Если нет** – выполните Шаг 5.

---

## Шаг 5. Копирование конфигурации из `assets/`

- В вашем скилле есть файл `assets/checkstyle-google.xml`.
- Скопируйте его в корень проекта под именем `checkstyle.xml`.
- Используйте команду (или выполните вручную):
  ```bash
  cp .qwen/skills/maven-checkstyle-setup/assets/checkstyle-google.xml ./checkstyle.xml
  ```
  (путь может отличаться в зависимости от места установки скилла)
- **Если копирование не удалось** – остановитесь с сообщением об ошибке.

---

## Шаг 6. Запуск проверки

- Выполните в корне проекта:
  ```bash
  mvn checkstyle:check
  ```
- **Если команда вернула ошибку** – сообщите вывод пользователю и предложите исправить нарушения.
- **Если успешно** – сообщите: «Checkstyle успешно настроен, проверка пройдена. Плагин будет автоматически выполняться на фазе validate.»

---
