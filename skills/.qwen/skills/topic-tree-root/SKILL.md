# Корневой скил дерева темы

Используй этот скил, когда пользователь просит объяснить тему в виде дерева и нужно проверить, как агент логирует переходы между скилами.

## Назначение

Этот скил является корневым узлом workflow.

Он должен начать древовидное объяснение темы, передать средний уровень скилу `topic-tree-branch`, а затем вернуть финальный ответ с проверочными маркерами.

## Обязательный workflow

1. Определи тему пользователя и подготовь корневой узел объяснения.
2. Первым tool-действием вызови `skill` tool строго с таким параметром:

```json
{
  "skill": "topic-tree-branch"
}
```

3. После загрузки `topic-tree-branch` сформируй финальный ответ.

## Обязательный формат финального ответа

Ответ должен быть на русском языке.

Верни ответ строго в такой структуре:

```text
TREE_ROOT_ENTER
Тема: {тема}

TREE_EDGE_ROOT_TO_BRANCH
TREE_BRANCH_ENTER
Дерево объяснения:
- Корень: {одно предложение о теме целиком}
  - Ветка 1: {первый главный аспект}
    - Лист 1.1: {конкретный факт или пример}
    - Лист 1.2: {конкретный факт или пример}
  - Ветка 2: {второй главный аспект}
    - Лист 2.1: {конкретный факт или пример}
    - Лист 2.2: {конкретный факт или пример}

TREE_BRANCH_SPLIT_DONE
TREE_EDGE_BRANCH_TO_LEAF
TREE_LEAF_ENTER
TREE_LEAF_EXAMPLES_DONE
TREE_LEAF_DONE
TREE_BRANCH_DONE

Итог: {короткое итоговое объяснение}

TREE_ROOT_DONE
```

Не пропускай, не переименовывай, не переводи и не меняй порядок marker-строк.

## Что проверять в логах

В `stream-json` должно быть видно:

1. Корневой скил был вызван как slash command `/topic-tree-root`.
2. Корневой скил вызвал `skill` tool для `topic-tree-branch`.
3. Финальный `type=result` содержит root, branch, leaf и transition markers.
