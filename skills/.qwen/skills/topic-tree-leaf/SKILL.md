# Листовой скил дерева темы

Используй этот скил только как последний узел workflow `topic-tree-root -> topic-tree-branch -> topic-tree-leaf`.

## Назначение

Этот скил отвечает за уровень листьев в дереве объяснения.

Он должен добавить конкретные примеры и проверочные маркеры, чтобы вызывающий код мог понять, что вложенный скил действительно был загружен.

## Обязательные маркеры

Финальный ответ должен содержать эти marker-строки:

```text
TREE_LEAF_ENTER
TREE_LEAF_EXAMPLES_DONE
TREE_LEAF_DONE
```

Не пропускай, не переименовывай, не переводи и не меняй порядок этих marker-строк внутри leaf-секции.

## Правила листьев

Для каждого листа:

1. Используй одно короткое предложение.
2. Лучше приведи конкретный пример, чем абстрактное определение.
3. Пиши на русском языке.
4. Не вызывай другие скилы из этого leaf-скила.

## Что проверять в логах

В `stream-json` должно быть видно, что этот скил был загружен через `skill` tool, а финальный результат содержит leaf markers.
