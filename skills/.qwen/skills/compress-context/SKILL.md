# Сжатие контекста текущей сессии (/compress)

Используйте этот навык, когда контекст qwen переполняется и его нужно
ужать. Навык запускает скрипт, который через встроенную команду
`/compress` делает AI-суммаризацию истории текущей (последней) сессии
проекта и сохраняет сжатую историю на диск.

> `/compress` заменяет историю диалога кратким резюме — детали могут
> потеряться, зато освобождается место в контексте.

## Предварительные требования

- Установлен `qwen` CLI (проверка: `qwen --version`).
- В проекте велась запись чата (сессия существует), иначе `--continue`
  не найдёт что сжимать. Список сессий: `qwen sessions list`.
- Скрипт `scripts/compress-context.sh` рядом с этим SKILL.md,
  исполняемый (`chmod +x`).

## Шаги выполнения

### Шаг 1: Сжать контекст текущей сессии

Запустить скрипт из каталога навыка:

```bash
bash .qwen/skills/compress-context/scripts/compress-context.sh
```

Скрипт возобновит последнюю сессию текущего проекта (`qwen --continue`)
и прогонит `/compress` в non-interactive режиме. По завершении qwen
выводит `Context compressed (<было> -> <стало>)` в токенах.

### Шаг 2 (опционально): Сжать конкретную сессию или задать инструкции

- Конкретная сессия по ID (см. `qwen sessions list`):
  ```bash
  bash .qwen/skills/compress-context/scripts/compress-context.sh <session-id>
  ```
- С дополнительными инструкциями для суммаризации (что важно сохранить):
  ```bash
  bash .qwen/skills/compress-context/scripts/compress-context.sh \
    -i "Сохрани решённые задачи по AQA Java и текущий прогресс курса"
  ```

## Примеры

### Пример 1

**Пользователь:**
Контекст переполняется — сожми его для текущей сессии.

**Ответ:**
Запускаю `scripts/compress-context.sh` → `Context compressed (128000 -> 24000)`.

### Пример 2

**Пользователь:**
Сожми контекст, но сохрани прогресс по курсу AQA Java.

**Ответ:**
Запускаю скрипт с `-i "Сохрани решённые задачи по AQA Java и прогресс"`.

## Формат ответа

Формат: `text`

```text
Context compressed (<originalTokenCount> -> <newTokenCount>)
```

## Ограничения

- Требуется, чтобы сессия ранее записывалась на диск (иначе `--continue`
  / `--resume` не сработают).
- AI-суммаризация тратит запрос к модели и может опустить мелкие детали.
- Для быстрого сжатия без модели существует `/compress-fast` (обрезает
  старые tool-выводы и thinking) — при необходимости замените команду в
  скрипте.
