# Веточный скил дерева темы

Используй этот скил только как средний узел workflow `topic-tree-root -> topic-tree-branch -> topic-tree-leaf`.

## Назначение

Этот скил отвечает за уровень веток в дереве объяснения.

Он должен разделить тему пользователя на две основные ветки, затем передать генерацию листьев скилу `topic-tree-leaf`.

## Обязательный workflow

1. Считай текущий запрос пользователя темой, переданной из `topic-tree-root`.
2. Перед финальным ответом вызови `skill` tool строго с таким параметром:

```json
{
  "skill": "topic-tree-leaf"
}
```

3. После загрузки `topic-tree-leaf` включи в финальный ответ branch и leaf markers.

## Обязательные маркеры

Финальный ответ должен содержать эти marker-строки:

```text
TREE_BRANCH_ENTER
TREE_BRANCH_SPLIT_DONE
TREE_EDGE_BRANCH_TO_LEAF
TREE_BRANCH_DONE
```

Не пропускай, не переименовывай, не переводи и не меняй порядок этих marker-строк внутри branch-секции.

## Правила ветвления

При объяснении темы:

1. Создай ровно две главные ветки.
2. У каждой ветки должно быть ровно два листа.
3. Каждая ветка должна объяснять отдельный аспект темы.
4. Каждый лист должен быть коротким и конкретным.

## Что проверять в логах

В `stream-json` должен появиться второй `tool_use` с `name=skill` и `input.skill=topic-tree-leaf`.
