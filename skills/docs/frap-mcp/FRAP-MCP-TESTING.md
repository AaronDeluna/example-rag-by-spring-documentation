# О Frap

Данный проект имеет многоуроневую структуру и несколько реализаций.

Одной из них является MCP-сервер.

Ссылка на исходный [код](https://github.com/kotler-dev/frap).

Запуск MCP-сервера для тестирования в командной строке через скрипт:
```shell
cd skills/docs/frap/
```
```shell
bash ./run_frap.sh 
```
