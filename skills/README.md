# Модуль для тестирования скиллов ИИ-агентов

## Запуск

1. В первую очередь необходимо в Maven запустить тесты для проверки доступности целевого для тестирования приложения Qwen путем выполнения команды:
    ```
    mvn clean test -pl skills -Dtest=QwenAvailabilityTest
    ```
2. В случае успешного выполнения команды из п.1 необходимо в файле, расположенном в текущем модуле по пути: `/.qwen/settings.json`
указать модель, запуск которой будет производиться.
3. Запустить тесты првоерки скиллов:
    ```
    mvn clean test -pl skills -Dtest=AgentSkillWorkflowTests
    ```

## Дополнительно

В проекте создан пример теста `MultipleModelsQwenTest` для тестирования одного запроса с разными моделями.
