## 🧩 Комплексное нагрузочное тестирование

Инструменты для оценки общих способностей агента решать многошаговые реальные задачи в терминале, часто в изолированных средах.

- **Terminal-Bench** — Индустриальный бенчмарк, запускающий агента в Docker-контейнерах с эталонными решениями и метриками точности. Имеет прямую поддержку в репозитории Qwen Code.
- **CLI Arena** — Новый фреймворк для оценки AI-агентов в сложных итеративных сценариях на реальных кодовых базах. Анализирует использование инструментов, эффективность команд и оптимальность траектории решений.
- **Harbor** — Фреймворк для запуска оценок агентов и создания сред для обучения с подкреплением (RL). Часто сравнивается с Terminal-Bench.
- **RA.Aid** — Автономный агент разработки, который можно использовать для тестирования производительности на задачах из SWE-Bench. Оценивает способность проводить многошаговые инженерные изменения в коде.
- **SWE-bench / SWE-Gym / R2E-Gym / LiveCodeBench / MLE-bench** — Набор стандартных бенчмарков для оценки навыков решения реальных задач (исправление багов, генерация кода, работа с ML). Широко применяются для сравнения агентов, в том числе в терминальной среде.
- **AstaBench** — Бенчмарк для оценки научных способностей AI-агентов: понимание литературы, анализ данных, планирование, использование инструментов, кодирование и поиск.
- **xbench** — Бенчмарк от Sequoia China, оценивающий верхнюю границу способностей AI-систем. Включает научные задачи и тесты на глубокий поиск в китайском интернете.
- **PICARD** — Фреймворк, генерирующий уникальные тестовые примеры через многослойную систематическую рандомизацию для проверки подлинных способностей агентов, а не запоминания.
- **MLflow** — Самая распространённая open-source платформа для оценки AI-агентов (30M+ загрузок в месяц). Поддерживает широкий спектр метрик, как правиловых, так и на основе LLM-судей.

## 🛠️ Тестирование конкретных навыков (Skills)

Инструменты, фокусирующиеся на изолированной проверке того, как агент обнаруживает, интерпретирует и выполняет отдельные навыки, описанные в `SKILL.md` или подобных форматах.

- **Waza** (Microsoft) — CLI-фреймворк на Go для тестирования навыков в стиле TDD. Позволяет генерировать шаблоны тестов на основе `SKILL.md` и сравнивать поведение разных LLM-моделей.
- **Skilljack Evals** — Node.js-библиотека, измеряющая три ключевые метрики: обнаруживаемость навыка, точность следования инструкциям и качество результата. Поддерживает локальный запуск и интеграцию с GitHub Actions.
- **SkillTester** — Агентно-ориентированная бенчмарк-система, которая помимо полезности навыка проверяет его безопасность (контроль действий, соблюдение границ разрешений). Имеет публичный дашборд `skilltester.ai`.
- **Huggingface UPskill** — Инструмент, генерирующий навыки на основе трассировок более мощных агентов-«учителей». Способен затем оценивать, насколько хорошо «слабый» агент-ученик выполняет созданный навык (команды `upskill generate` и `upskill eval`).
- **ClawEnvKit** — Инструментарий для создания тестовых сред, ориентированный на агентов типа «коготь» (OpenClaw и аналоги). Автоматически генерирует задачи из описаний на естественном языке.
- **Skilldoc** — Автоматический генератор документации `SKILL.md` на основе вывода `--help` CLI-инструмента. Использует несколько LLM для извлечения, сжатия и валидации инструкций, гарантируя их точность.
- **Skillscore** — Универсальный стандарт оценки качества `SKILL.md`-файлов. Выставляет баллы по 7 категориям: ясность, безопасность, метаданные и т.д. Поддерживает пакетное сравнение навыков из разных источников.

## ⚙️ Специализированные инструменты

Нишевые решения, покрывающие отдельные аспекты тестирования: безопасность, трассировку, сценарные проверки, CI/CD и анализ сессий.

### 🔒 Тестирование безопасности
- **CheckAgent** — Плагин для `pytest`, который прогоняет до 101 атакующего запроса на агента (инъекции, утечки PII, нецелевое использование инструментов). Работает с любым агентом, доступным через HTTP или Python-функцию.

### 📊 Тестирование через трассировку
- **Agentevals** — Фреймворк для оценки поведения агента по трассам OpenTelemetry. Позволяет проигрывать записанные сессии без повторного запуска дорогостоящих LLM-вызовов.

### 🎭 Сценарное / приемочное тестирование и CI/CD
- **Agentest** — Инструмент, симулирующий поведение пользователя в реалистичных сценариях. Перехватывает вызовы инструментов, оценивает каждый шаг с помощью LLM-судьи и легко встраивается в CI/CD пайплайны.
- **Agentic Usability** — CLI-инструмент от PSPDFKit, проверяющий, насколько хорошо AI-агенты могут использовать ваш SDK. Генерирует задачи на основе кода, запускает агента в «песочнице» и сравнивает результат с эталонным.
- **Aethr** — CLI-агент для запуска тестовых сценариев, описанных на естественном языке. Использует LLM и MCP-инструменты для планирования и выполнения приемочного тестирования.

### 📋 Анализ и бенчмаркинг сессий
- **Agent Harness** — Инструмент для сравнительного анализа сессий агента на основе структурированных логов. Оценивает завершение задач, эффективность, качество восстановления после ошибок и выставляет итоговый балл сессии.

## 🧪 Тестирование MCP-серверов

Инструменты для проверки работоспособности, безопасности, производительности и соответствия спецификациям серверов Model Context Protocol (MCP).

### ✅ Валидация и отладка
- **MCP Test Kit (`@cybeleri/mcp-test-kit`)** — CLI-фреймворк для комплексной проверки MCP-серверов перед развертыванием. Проводит валидацию, бенчмаркинг и аудит безопасности для выявления распространенных уязвимостей (по данным создателей, 88% MCP-серверов имеют проблемы с безопасностью). Поддерживает интеграцию с CI/CD.
- **MCP Server Tester** — Не зависящий от реализации CLI-инструмент для автоматизированного тестирования. Предлагает три команды: `tools` (прямые вызовы API), `evals` (проверка того, как LLM использует инструменты) и `compliance` (валидация на соответствие спецификации, в разработке).
- **MCP Conformance Test Framework** — Официальный фреймворк от сообщества MCP для проверки клиентских и серверных реализаций на соответствие спецификации протокола. Находится в активной разработке.
- **MCP Probe (`mcp-probe`)** — Клиентская библиотека и отладочный инструментарий на Rust. Предоставляет SDK для интеграций и интерактивный отладчик с терминальным интерфейсом (TUI) для тестирования MCP-серверов.
- **MCP Debug (`mcp-debug`)** — Инструмент командной строки для отладки MCP-серверов. Помогает разработчикам проверять возможности сервера, тестировать интеграцию инструментов и отслеживать уведомления сервера. Поддерживает транспорт `streamable-http` и OAuth 2.1 аутентификацию.
- **MCP Playground** — Веб-инструмент с открытым исходным кодом для интроспекции и тестирования MCP-серверов прямо из браузера. Поддерживает HTTP-транспорт, интерактивное тестирование инструментов, ресурсов и промптов, а также отладку OAuth-потоков.
- **MCP Tester (`mcp-tester`)** — "Швейцарский нож" для тестирования MCP-серверов в виде единого бинарного файла. Проверяет соответствие протоколу, тестирует инструменты, генерирует сценарии и диагностирует проблемы с подключением.
- **Hoot** — Инструмент тестирования MCP в стиле Postman. Позволяет тестировать, отлаживать и исследовать MCP-серверы через красивый веб-интерфейс. Поддерживает OAuth 2.1 и не требует AI-чата.
- **MCP Inspector** — Визуальный отладчик с GUI для Model Context Protocol. Позволяет просматривать инструменты, ресурсы и промпты в реальном времени, вызывать инструменты с JSON-параметрами и отслеживать двунаправленный JSON-RPC трафик.
- **MCP Tools (`mcptools`)** — Универсальный CLI для взаимодействия с MCP-серверами. Поддерживает обнаружение и вызов инструментов, создание mock-серверов для тестирования клиентов и проксирование запросов.

### 🛡️ Безопасность и стресс-тестирование
- **MCPSafe** — Первый опенсорсный фреймворк для аудита безопасности и стресс-тестирования *работающих* MCP-серверов. В отличие от инструментов статического анализа, подключается к серверу и активно тестирует его на устойчивость к инъекциям, путанице типов, утечкам данных и проблемам с аутентификацией.
- **Inspector Grizzly (`@alpic-ai/grizzly`)** — Визуальный инструмент на базе MCP Inspector с расширенными функциями. Включает анализатор сервера для поиска уязвимостей (например, Prompt Injection), генератор тестовых сценариев и набор тестов для оценки "обнаруживаемости" MCP-сервера.
- **MCP Client Inspector** — "Злонамеренный" MCP-сервер для аудита безопасности *клиентов* (Cursor, Claude Code и др.). Проверяет, как клиент защищается от атак со стороны вредоносного сервера: коллизий имен инструментов, инъекций в промпты, переполнения контекста и т.д.

### 🚀 Нагрузочное тестирование и бенчмаркинг
- **MCP Benchmark Runner (`mcpbr`)** — Бенчмарк для оценки того, насколько MCP-сервер улучшает производительность агента. Проводит контролируемые эксперименты на реальных задачах из SWE-bench, сравнивая результаты с базовым агентом без доступа к серверу.
- **LiveMCPBench** — Крупномасштабный бенчмарк, оценивающий способность LLM-агентов ориентироваться в "океане" MCP-инструментов. Включает 70 серверов и 527 инструментов, моделируя реалистичные сценарии маршрутизации и композиции инструментов.
- **MCPToolBench++** — Крупномасштабный бенчмарк использования инструментов AI-агентами, включающий более 4000 MCP-серверов из 45+ категорий. Оценивает способности агентов в обнаружении, выборе и вызове инструментов.
- **Benchmark MCP (`benchmark-mcp`)** — Node.js клиент для проведения нагрузочного тестирования MCP-серверов. Поддерживает различные режимы, включая последовательные вызовы, случайные вызовы инструментов и вызов всех доступных инструментов.

### ⚙️ Автоматизация, оценка и приемочное тестирование
- **MCP Observatory** — Инструмент тестирования, который сам является MCP-сервером. Позволяет AI-агенту автономно сканировать, тестировать, записывать и верифицировать другие MCP-серверы, выявляя регрессии и проблемы безопасности.
- **MCP-Eval (`python-mcp-eval`)** — Фреймворк в стиле `pytest` для оценки MCP-серверов. Позволяет писать тесты, в которых AI-агент выполняет задачу, и автоматически собирает метрики (задержка, использование токенов, стоимость).
- **MCP Interviewer** — Python CLI инструмент от Microsoft Research для раннего выявления проблем MCP-серверов. Проверяет ограничения, проводит функциональное тестирование с использованием LLM и генерирует отчеты с оценкой готовности сервера к работе с агентами.
- **MCPVals** — Комплексная библиотека для оценки MCP-серверов с покрытием всей спецификации. Поддерживает детерминированные метрики, проверки безопасности и опциональную оценку на основе LLM. Интегрируется с `vitest`.

## 📊 Тестирование LLM-моделей

Инструменты для оценки качества, безопасности и производительности самих языковых моделей.

- **Vertex AI Evaluation** — Управляемый сервис Google Cloud для оценки GenAI-систем. Автоматизирует оценку качества, безопасности и полезности ответов модели по заданным метрикам.
- **Agent Development Kit (ADK)** — Инструментарий от Google для трассировки и оценки решений агентов. Позволяет определять критерии оценки процесса рассуждения и визуализировать результаты.
- **DeepEval** — Фреймворк с открытым исходным кодом в стиле `pytest`. Предлагает более 50 метрик для оценки RAG, агентов, безопасности и мультимодальных систем. Интегрируется в CI/CD пайплайны.
- **Deepchecks** — Платформа для непрерывной валидации LLM-приложений на протяжении всего жизненного цикла. Автоматизирует проверку на смещения, устойчивость и интерпретируемость.
- **HELM (Stanford)** — Фреймворк для целостной оценки языковых моделей по множеству измерений: точность, калибровка, устойчивость, безопасность и предвзятость.
- **LM Evaluation Harness** — Фреймворк, поддерживающий более 60 стандартных академических бенчмарков для LLM, включая MMLU, GSM8K и HellaSwag.
- **Bloom (Anthropic)** — Опенсорсный агентный фреймворк для генерации поведенческих оценок frontier-моделей. Количественно определяет частоту и серьезность заданного поведения.
- **EvalScope** — Официальный фреймворк ModelScope для оценки моделей. Поддерживает LLM, мультимодальные, embedding и reranker модели. Включает бенчмарки MMLU, CMMLU, C-Eval, GSM8K и интеграцию с RAGAS и MTEB.
- **AgentEval** — .NET тулкит для оценки AI-агентов: валидация использования инструментов, метрики качества RAG, стохастическая оценка, сравнение моделей и тестирование безопасности red team.

## 🧪 Тестирование эмбеддеров и поисковых систем

Инструменты для оценки качества моделей эмбеддингов и retrieval-систем.

- **MTEB (Massive Text Embedding Benchmark)** — Мультимодальный инструментарий для оценки эмбеддингов и retrieval-систем. Покрывает более 1000 языков и разнообразные задачи: классификация, кластеризация, реранкинг и retrieval.
- **RTEB (Retrieval Embedding Benchmark)** — Новый стандарт для оценки истинной точности retrieval эмбеддингов. Использует гибридную стратегию для обеспечения подлинного обобщения.
- **NVIDIA NeMo Evaluator** — Контейнеризированное решение для оценки моделей, совместимое с MTEB. Предоставляет CLI для запуска различных оценок эмбеддингов и LLM.
- **VDBBench** — Инструмент для бенчмаркинга векторных баз данных. Поддерживает сравнение Milvus, Elasticsearch, pgvector и других, симулируя реальные производственные нагрузки.
- **HUME** — Бенчмарк, измеряющий разрыв между производительностью человека и модели в задачах текстовых эмбеддингов. Улучшает интерпретируемость оценки моделей.

## 🔍 Тестирование RAG-систем

Инструменты для оценки компонентов retrieval-augmented generation пайплайнов.

- **RAGAS** — Фреймворк для оценки RAG-пайплайнов без необходимости в эталонных ответах. Предоставляет метрики: faithfulness, answer relevancy, context precision и context recall.
- **TruLens** — Фреймворк с функциями обратной связи и трассировкой OpenTelemetry. Силен в интеграции мониторинга для LLM-приложений и агентов.
- **RAGChecker** — Продвинутый фреймворк для оценки и диагностики RAG-систем. Предоставляет комплексные метрики, диагностические индикаторы и тонкую оценку производительности.
- **MLflow LLM Evaluate** — Модуль MLflow для оценки LLM. Известен модульностью и простотой, может использоваться в кастомных пайплайнах оценки.

## 🛡️ Безопасность и Red Teaming

Инструменты для проверки устойчивости AI-систем к атакам и нежелательному поведению.

- **AI-Infra-Guard (Tencent)** — Полнофункциональная платформа для red teaming AI-экосистем. Включает сканирование OpenClaw, агентов, навыков, MCP-серверов, AI-инфраструктуры и оценку jailbreak-уязвимостей.
- **Giskard** — Платформа для тестирования и red teaming LLM-агентов. Включает автоматическое обнаружение уязвимостей безопасности и сбоев бизнес-логики, непрерывный red teaming и командную коллаборацию.
- **ai-blackteam** — Автоматизированный фреймворк для red teaming LLM. Запускает 89 многоходовых адаптивных атак, включая обфускацию, психологические и агентные векторы эксплуатации. Соответствует MITRE ATLAS, OWASP LLM Top 10.
- **Highflame RED** — Инструмент для автономного адверсариального тестирования AI-агентов. Проводит автоматическую разведку возможностей агента и генерирует целевые тестовые сценарии.
- **HackMyAgent** — Тулкит безопасности, включающий 209 проверок безопасности, 29 семантических проверок и симуляцию поведения. Использует семантический анализ вместо регулярных выражений для низкого уровня ложных срабатываний.
- **Akto Agent Probe** — Движок автоматизированного red teaming для агентного AI. Непрерывно тестирует безопасность с глубоким сканированием MCP и ролевой оценкой.
- **AI Red Teaming Agent (Microsoft)** — Инструмент для проактивного поиска рисков безопасности в генеративных AI-системах. Проводит автоматическое сканирование и симулирует адверсариальное зондирование.
- **Basilisk** — Опенсорсный фреймворк для red teaming с генетической эволюцией промптов. Покрывает OWASP LLM Top 10 и включает 32 модуля атак.

🛠️ Тестирование конкретных навыков (Skills) — дополнение
Tool Calling Benchmark (MikeVeerman) — Эталонный тест для оценки способности небольших локальных моделей определять, когда нужно вызывать инструмент, а когда — воздержаться. Запускается на CPU с Ollama и 1‑4-битными квантованными моделями, измеряя «Agent Score» как комбинацию Action (правильные вызовы) и Restraint (правильные отказы от вызова).

Tool Calling Bench (Zux1U) — Локальный бенчмарк для моделей llama.cpp в OpenAI‑совместимом режиме. Проверяет качество вызова инструментов, restraint, выбор правильного инструмента, согласованность при повторных запусках и поддержку нескольких инструментов одновременно. Итоговый «Agent Score» рассчитывается по взвешенной формуле.
