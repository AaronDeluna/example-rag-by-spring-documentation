## HippoRAG — агрегированное описание

### 1. Что это такое

**HippoRAG** — это фреймворк класса RAG (Retrieval-Augmented Generation), разработанный группой NLP Университета штата Огайо (OSU NLP Group). Его ключевая особенность — имитация механизмов **долговременной памяти человека** для связывания разрозненных фактов и выполнения сложных многошаговых рассуждений.

- **Вдохновение**: теория индексации гиппокампа (работа мозга, при которой хранятся не сами воспоминания, а ассоциативные связи между ними).
- **Статус**: представлен на **NeurIPS 2024**, активно развивается. На GitHub имеет **3,3k+ звёзд**.
- **Текущая версия**: в репозитории разрабатывается **HippoRAG 2** — улучшенная итерация, расширяющая возможности первой версии.

---

### 2. Архитектура и принцип работы

HippoRAG строится на трёх компонентах, зеркально отражающих структуры мозга:

| Компонент | Роль в HippoRAG | Аналог в мозге |
|-----------|----------------|-----------------|
| **LLM** (большая языковая модель) | Извлекает из текста структурированные факты — **триплеты** «субъект‑отношение‑объект» | Неокортекс |
| **Граф знаний** | Хранит все извлечённые сущности и связи между ними — долговременная «память» системы | Гиппокамп |
| **Алгоритм Personalized PageRank (PPR)** | При запросе «гуляет» по графу, начиная с релевантных узлов, и находит скрытые ассоциативные цепочки | Ассоциативное мышление |

**Процесс работы:**
- **Индексация**: документы разбиваются на чанки, из каждого LLM извлекаются триплеты, которые добавляются в граф знаний.
- **Поиск**: запрос преобразуется в начальные узлы графа, PPR выявляет все релевантные цепочки связей за один проход.
- **Генерация ответа**: контекст, полученный из графа, подаётся LLM для формирования финального ответа.

---

### 3. Ключевые отличия от традиционного RAG

| Характеристика | Традиционный RAG | HippoRAG |
|----------------|------------------|----------|
| **Механизм поиска** | Сравнение эмбеддингов запроса и чанков | Семантический поиск + **PPR по графу знаний** |
| **Связывание фактов** | Связывает запрос с отдельными фрагментами | Связывает фрагменты **друг с другом**, выстраивая цепочки рассуждений |
| **Многошаговые запросы** | Требует итеративных вызовов LLM (дорого, медленно) | Решает **за один шаг**, что в 10–30 раз дешевле и в 6–13 раз быстрее |
| **Производительность на сложных бенчмарках** | Низкая | Превосходит аналоги **до 20%** (MuSiQue, 2WikiMultiHopQA) |

---

### 4. Версии: HippoRAG и HippoRAG 2

- **HippoRAG (1)**: силён в многошаговых рассуждениях, но немного уступал классическому RAG на простых фактологических вопросах.
- **HippoRAG 2** (из статьи и репозитория):
    - Улучшен как в рассуждениях, так и в задачах на запоминание фактов — **превосходит стандартный RAG по всем метрикам**.
    - Прирост **Recall@5**: +5.0% на MuSiQue, +13.9% на 2WikiMultiHopQA.
    - Поддерживает инкрементальное обновление графа (добавление и удаление документов без перестройки).

---

### 5. Основные функции (Python API)

Все действия выполняются через Python-библиотеку `hipporag`.

- **`index(docs)`** — индексация документов: разбивка, извлечение триплетов, построение графа.
- **`retrieve(queries)`** — поиск релевантных чанков/триплетов без генерации ответа.
- **`rag_qa(queries)`** — полный цикл: поиск контекста + генерация ответа LLM.
- **`delete_docs(doc_ids)`** — удаление документов из графа без переиндексации остального.

Встроенные метрики (при наличии эталона): `retrieval_hit_rate`, `answer_accuracy`, `latency_seconds`.

### 6. Установка и развёртывание

```bash
pip install hipporag
```

**Гибкость бэкендов:**
- Поддержка **OpenAI API** и локальных моделей через **vLLM**.
- Возможность поднять собственный FastAPI-сервер, совместимый с API OpenAI, для приватного использования.

---

### 7. Прикладная ценность

HippoRAG ориентирован на сценарии, где ответ требует связывания фактов из нескольких источников (юридический анализ, научные исследования, медицинская диагностика по разрозненным данным). За счёт однопроходного механизма он радикально снижает стоимость и время сложных запросов, сохраняя при этом высокое качество генерации. Сообщество и научная публикация на NeurIPS подтверждают его статус одного из самых перспективных направлений в эволюции RAG-систем.
