## 🧠 Общее описание

**Crawl4AI** — это опенсорсный веб-краулер и скрейпер, оптимизированный для работы с большими языковыми моделями (LLM).  
Его главная цель — превращать любые веб-страницы в чистый, структурированный Markdown, пригодный для прямого использования в AI-агентах, RAG-системах и конвейерах данных.

### Ключевые возможности и принцип работы
- **Генерация LLM-дружественного Markdown** из сложного HTML.
- **Асинхронное управление headless-браузером** (Playwright) с кешированием, пулом сессий и обходом антибот-систем.
- **Извлечение структурированных данных** через CSS-селекторы или интеллектуальные стратегии с применением LLM.
- **Работа с медиа** (скриншоты, извлечение информации об изображениях, аудио, видео).

## 🖼️ Работа с изображениями

Crawl4AI обрабатывает изображения в трёх направлениях:

1. **Создание скриншотов**
    - `screenshot=True` — скриншот всей страницы (при длинных страницах — склейка с прокруткой, либо через PDF).
    - `force_viewport_screenshot=True` — скриншот только видимой области.
    - Результат возвращается в Base64 внутри `result.screenshot`.

2. **Извлечение информации о медиафайлах**
    - Автоматически собирается словарь `result.media` для тегов `<img>`, `<audio>`, `<video>`.
    - Для каждого файла сохраняются `src`, `alt`, тип, а также **оценка полезности (`score`)**, позволяющая отсеивать декоративные элементы.
    - Настраивается опциями `exclude_external_images`, `exclude_all_images`.

3. **Продвинутая обработка**
    - Обнаружение lazy‑loading, поддержка base64‑изображений.
    - При использовании `LLMExtractionStrategy` можно поручить модели описать изображения на основе окружающего текста или атрибута `alt`.

## 🚀 Запуск на удалённой машине

Рассмотрены два основных способа, а также CLI-вариант.

### 1. Запуск как Python-библиотеки
```bash
# Установка
pip install crawl4ai
crawl4ai-setup

# Использование
import asyncio
from crawl4ai import AsyncWebCrawler

async def main():
    async with AsyncWebCrawler(verbose=True) as crawler:
        result = await crawler.arun(url="https://example.com")
        print(result.markdown)

asyncio.run(main())
```
- Для фоновой работы рекомендуется `tmux` / `screen` или создание `systemd`-сервиса.

### 2. Запуск как Docker-сервиса (рекомендуемый способ)
```bash
docker run -d \
  -p 11235:11235 \
  --name crawl4ai \
  --shm-size=2g \
  unclecode/crawl4ai:latest
```
- Автоматически поднимается FastAPI-сервер на порту 11235.
- Дополнительно можно передать переменные окружения (например, `OPENAI_API_KEY`) и настроить автозапуск через `--restart=always`.
- Для production удобнее использовать `docker-compose.yml`.

### 3. CLI
```bash
crwl https://example.com -o output.json
```
Доступен после установки Python-пакета.

## 🌐 REST API для интеграции

При запуске в Docker-режиме Crawl4AI предоставляет полноценный REST API.

### Основные эндпоинты

| Эндпоинт          | Метод  | Назначение |
|-------------------|--------|------------|
| `/crawl`          | POST   | Синхронный краулинг (ожидает полного результата) |
| `/crawl_async`    | POST   | Асинхронный запуск (возвращает `task_id`) |
| `/task/{task_id}` | GET    | Получение статуса и результата асинхронной задачи |
| `/health`         | GET    | Проверка доступности сервиса |
| `/docs`           | GET    | Авто‑документация Swagger |
| `/playground`     | GET    | Веб‑интерфейс для ручного тестирования |

### Пример синхронного вызова (curl)
```bash
curl -X POST http://<IP>:11235/crawl \
  -H "Content-Type: application/json" \
  -d '{"urls": ["https://example.com"], "screenshot": true}'
```

### Пример асинхронного запуска (curl)
```bash
# Отправка задачи
TASK_ID=$(curl -s -X POST http://<IP>:11235/crawl_async \
  -H "Content-Type: application/json" \
  -d '{"urls": ["https://httpbin.org/delay/5"]}' | jq -r '.task_id')

# Опрос статуса
curl http://<IP>:11235/task/$TASK_ID
```

Формат тела запроса совпадает с параметрами Python-метода `arun()` (подробно описан в Swagger).

## 📤 Возвращаемый результат (объект `CrawlResult`)

После выполнения задачи возвращается объект со следующими ключевыми полями:

| Поле                 | Содержимое |
|----------------------|------------|
| `html`               | Исходный HTML страницы, без изменений |
| `cleaned_html`       | Очищенный HTML (удалены скрипты, стили) |
| `markdown`           | Конвертированный Markdown (может включать `raw_markdown`, `fit_markdown`) |
| `screenshot`         | Base64-строка скриншота (если запрошен) |
| `media`              | Словарь с информацией об изображениях, аудио и видео |
| `extracted_content`  | Результат работы стратегии извлечения (CSS или LLM) — структурированный JSON или текст |

Таким образом, пользователь может получить:
- **Исходную страницу** (`html`)
- **Обработанный, «чистый» контент** (`cleaned_html`, `markdown`)
- **Интеллектуально извлечённые данные** (`extracted_content`) — результат, сгенерированный моделью или собранный по CSS-селекторам.

## 🧩 Резюме

Crawl4AI — это гибкое решение, способное работать как:
- **библиотека**, встраиваемая в Python-код;
- **микросервис** с REST API для интеграции с любыми языками;
- **инструмент командной строки** для разовых задач.

Он забирает на себя все этапы — от рендеринга сложных JavaScript-сайтов до финальной подготовки чистых, пригодных для ИИ данных, а также предоставляет богатые возможности по работе с изображениями и извлечению информации с помощью LLM.
