# Дублирование кода

**Категория:** Стиль кодирования (Clean Code)

**Описание:** Одинаковые фрагменты кода встречаются в разных местах.

**Инструменты:** PMD, Checkstyle

---

Вот пример, демонстрирующий проблему дублирования кода, её исправление и способ обнаружения с помощью инструментов статического анализа.

---

### Корректный пример

Вместо дублирования логики вычисления скидки и форматирования вынесем её в отдельный утилитарный метод.

```java
public class OrderService {

    public String processOrder(Order order, Customer customer) {
        double discount = calculateDiscount(customer);
        double finalPrice = order.getPrice() * (1 - discount);
        return formatPrice(finalPrice);
    }

    public String processSubscription(Subscription subscription, Customer customer) {
        double discount = calculateDiscount(customer);
        double finalPrice = subscription.getPrice() * (1 - discount);
        return formatPrice(finalPrice);
    }

    // Вынесенная общая логика
    private double calculateDiscount(Customer customer) {
        if (customer.isPremium()) {
            return 0.2;
        } else if (customer.isVip()) {
            return 0.1;
        }
        return 0.0;
    }

    private String formatPrice(double price) {
        return String.format("%.2f", price);
    }
}

// Вспомогательные классы для примера
class Order {
    private double price;
    public double getPrice() { return price; }
}

class Subscription {
    private double price;
    public double getPrice() { return price; }
}

class Customer {
    public boolean isPremium() { return false; }
    public boolean isVip() { return false; }
}
```

**Почему это хорошо:**  
- Логика расчёта скидки и форматирования определена в одном месте.  
- При изменении правил скидки достаточно поправить один метод.  
- Код стал короче, читаемее и легче для тестирования.

### Некорректный пример

Дублирование одной и той же логики расчёта скидки и форматирования цены в двух методах.

```java
public class OrderService {

    public String processOrder(Order order, Customer customer) {
        double discount;
        if (customer.isPremium()) {
            discount = 0.2;
        } else if (customer.isVip()) {
            discount = 0.1;
        } else {
            discount = 0.0;
        }
        double finalPrice = order.getPrice() * (1 - discount);
        return String.format("%.2f", finalPrice);
    }

    public String processSubscription(Subscription subscription, Customer customer) {
        double discount;
        if (customer.isPremium()) {
            discount = 0.2;
        } else if (customer.isVip()) {
            discount = 0.1;
        } else {
            discount = 0.0;
        }
        double finalPrice = subscription.getPrice() * (1 - discount);
        return String.format("%.2f", finalPrice);
    }
}

// Вспомогательные классы
class Order {
    private double price;
    public double getPrice() { return price; }
}

class Subscription {
    private double price;
    public double getPrice() { return price; }
}

class Customer {
    public boolean isPremium() { return false; }
    public boolean isVip() { return false; }
}
```

---

### Объяснение и выявление инструментом

**Почему это плохо:**
- **Дублирование кода** — одни и те же блоки `if-else` и форматирование повторяются в двух методах.
- Нарушает принцип **DRY (Don't Repeat Yourself)**.
- Если потребуется изменить размер скидки для VIP-клиента, придётся править код в двух местах, что увеличивает риск ошибки.
- Усложняет поддержку и рефакторинг.

**Какой инструмент обнаружит проблему и как:**

1. **PMD** — правило `Copy/Paste Detector (CPD)`.
   - CPD анализирует исходный код и находит идентичные или очень похожие фрагменты кода (обычно от 100 токенов).
   - В данном примере он обнаружит, что блоки `if-else` и `String.format` полностью повторяются, и выдаст предупреждение о дублировании.

2. **Checkstyle** — правило `DuplicateCode` (требует дополнительной конфигурации, но поддерживается).
   - Может быть настроен на поиск повторяющихся строк или блоков кода через модуль `Checker` с `TreeWalker`.

**Пример сообщения от PMD CPD:**
```
Found a 7 line (44 tokens) duplication in the following files:
  - OrderService.java (line 12)
  - OrderService.java (line 26)
```
Это укажет на точные строки, где встречается дублирование.
