## Описание

Требуется реализовать тесты для проверки влияния параметров модели-эмбеддера при векторизации запросов в RAG на итоговый ответ от RAG-системы.

**Контекст:**
- Модели-эмбеддеры имеют параметры (размерность, нормализация, etc.)
- Изменение параметров может влиять на качество векторизации
- Качество векторизации влияет на поиск в векторной базе и ответ RAG

**Цель:**
- Оценить влияние параметров эмбеддера на релевантность ответов RAG
- Выявить оптимальные параметры для текущей RAG-системы

## Заметки

### Параметры для тестирования

- Размерность вектора (dimension)
- Нормализация вектора (normalize)
- Максимальная длина токенов (max_tokens)

### Метрики качества

- Релевантность ответа (relevance score)
- Точность поиска (precision@k)
- Полнота поиска (recall@k)
