## Описание

Требуется оценить применимость библиотеки RAGAS (Retrieval Augmented Generation Assessment) для тестирования RAG-системы в проекте.

**Контекст:**
- RAGAS — библиотека для оценки качества RAG-систем
- Предоставляет метрики: faithfulness, answer relevance, context relevance
- Необходимо оценить применимость к Spring AI RAG

**Цель:**
- Изучить библиотеку RAGAS
- Оценить возможность интеграции с Spring AI
- Подготовить рекомендации по применению

## Заметки

### Метрики RAGAS

- **Faithfulness** — соответствие ответа контексту
- **Answer Relevance** — релевантность ответа вопросу
- **Context Relevance** — релевантность контекста
- **Context Recall** — полнота контекста
