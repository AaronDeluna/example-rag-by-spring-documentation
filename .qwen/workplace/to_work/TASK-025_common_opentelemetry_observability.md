## Описание

Требуется добавить observability для MCP-сервера через OpenTelemetry для мониторинга и трассировки запросов.

**Контекст:**
- OpenTelemetry — стандарт де-факто для observability
- Позволяет трассировать запросы между компонентами
- Интегрируется с Spring Boot через spring-boot-starter-actuator

**Цель:**
- Настроить OpenTelemetry для MCP-сервера
- Реализовать трассировку JSON-RPC запросов
- Обеспечить визуализацию через UI (Grafana/Jaeger)

## Заметки

### Компоненты OpenTelemetry

- **Tracing** — трассировка запросов
- **Metrics** — метрики производительности
- **Logs** — структурированные логи

### Варианты развёртывания

- Отдельный endpoint для метрик (/metrics)
- Экспорт в Jaeger/Zipkin
- Кастомный сборщик с визуализацией
