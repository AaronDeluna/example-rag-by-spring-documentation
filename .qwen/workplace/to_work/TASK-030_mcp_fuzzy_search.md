## Описание

Добавить возможность поиска классов по частичному совпадению имени. Сейчас поиск требует точного совпадения имени файла класса.

**Проблема:** При запросе `KafkaTemplate` поиск ищет файл `KafkaTemplate.class`. Если пользователь ошибся в регистре или ввёл частичное имя (например, `Kafka`), поиск вернёт пустой результат.

## Критерии приёмки

- [ ] Реализован поиск по подстроке (contains)
- [ ] Поддержка case-insensitive поиска
- [ ] Возвращается до 10 лучших совпадений
- [ ] Сортировка результатов по релевантности (точное совпадение > startsWith > contains)

## Пример поведения

**Вход:**
```json
{"class_name": "Kafka"}
```

**Выход:**
```
Найдено совпадений по запросу 'Kafka':

Точное совпадение:
  KafkaTemplate.class в spring-kafka-3.0.0.jar

Похожие классы:
  KafkaAdmin.class в ...
  KafkaConsumer.class в ...
```
