## Описание

Необходимо провести тестирование производительности MCP-сервера `mcp-server-jar-unpacker` для оценки времени выполнения операций инструментов.

**Цель:** Получить метрики времени выполнения для каждого инструмента MCP-сервера:
- `find_class_in_m2`
- `get_class_outline`
- `decompile_class`
- `get_method_source`
- `list_classes_in_jar`
- `search_classes_by_pattern`

**Подход:**
1. Включить DEBUG-логирование с временными метками
2. Выполнить серию вызовов каждого инструмента
3. Зафиксировать время выполнения из логов
4. Составить отчёт с метриками производительности
