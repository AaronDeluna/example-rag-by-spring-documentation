## Описание

## Критерии приёмки

- [ ] Логировать попадание в кэш

## Пример лога

```
2026-03-27T01:00:00.000Z | CACHE HIT | getJars() | размер: 1523 JAR
2026-03-27T01:05:00.000Z | CACHE MISS | getJars() | причина: TTL истёк (300 сек)
2026-03-27T01:05:00.100Z | CACHE UPDATE | найдено 1525 JAR (+2)
```
