## Описание

Требуется добавить логирование входящих запросов к MCP-серверу для отладки и мониторинга взаимодействия с клиентами.

**Контекст:**
- MCP-сервер получает запросы через JSON-RPC 2.0
- Отсутствует детальное логирование входящих запросов
- Необходимо для отладки и аудита взаимодействия

**Цель:**
- Логировать все входящие запросы к MCP-серверу
- Логировать ответы сервера
- Обеспечить возможность анализа логов

## Критерии приёмки (Acceptance Criteria)

- [ ] Настроено логирование входящих JSON-RPC запросов
- [ ] Логи содержат: метод, параметры, id запроса
- [ ] Логи содержат: результат выполнения, время обработки
- [ ] Настроен формат логов (JSON или структурированный)
- [ ] Логи не содержат чувствительных данных
- [ ] Написаны тесты на логирование

## Заметки

### Способы логирования

- Logbook (org.zalando) — уже используется в проекте
- Custom Logger через JsonRpcHandler
- Transport-level logging

### Формат лога

```json
{
  "timestamp": "2026-03-26T10:00:00.000Z",
  "direction": "INBOUND",
  "method": "tools/call",
  "params": {"name": "find_class_in_m2"},
  "id": 1,
  "elapsed_ms": 45
}
```
