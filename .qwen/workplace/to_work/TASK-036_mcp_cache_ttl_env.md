## Описание

Разрешить настройку TTL кэша через переменную окружения.

## Критерии приёмки

- [ ] Переменная окружения `CACHE_TTL_SECONDS` (по умолчанию 300)
- [ ] Системное свойство `cache.ttl.seconds`
- [ ] Валидация: мин. 60 сек, макс. 3600 сек

## Пример

```bash
export CACHE_TTL_SECONDS=600  # 10 минут
java -jar mcp-server-jar-unpacker-1.0-SNAPSHOT.jar
```
