## Описание

Требуется реализовать тесты для сравнения векторов, полученных от разных моделей-эмбеддеров в RAG-системе.

**Контекст:**
- RAG-система использует модели-эмбеддеры для векторизации запросов
- Разные модели могут давать различные вектора для одного запроса
- Необходимо оценить влияние выбора модели на качество поиска в RAG

**Цель:**
- Сравнить вектора от разных моделей-эмбеддеров для одинаковых запросов
- Оценить косинусное сходство между векторами
- Выявить модели с наилучшей согласованностью
