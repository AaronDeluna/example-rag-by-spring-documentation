## Описание

Требуется расширить тестовый эмулятор MCP-клиента поддержкой многопоточных вызовов инструментов MCP-сервера.

**Контекст:**
- MCP-сервер должен обрабатывать множественные параллельные запросы
- Требуется тестирование на конкурентность
- WebFlux обеспечивает реактивную обработку запросов

**Цель:**
- Реализовать многопоточный вызов инструментов MCP-сервера
- Протестировать производительность и стабильность
- Выявить проблемы конкурентности

## Критерии приёмки (Acceptance Criteria)

- [ ] Расширен McpClientEmulator поддержкой многопоточности
- [ ] Реализован пул потоков для параллельных вызовов
- [ ] Создан тест на нагрузку (минимум 100 параллельных запросов)
- [ ] Измерено время обработки запросов
- [ ] Выявлены и устранены deadlock-и (если есть)
- [ ] Написан отчёт о производительности
