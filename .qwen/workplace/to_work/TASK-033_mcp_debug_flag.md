## Описание

Добавить параметр командной строки `--debug` для включения подробного логирования.

## Критерии приёмки

- [ ] Флаг `--debug` в аргументах командной строки
- [ ] В DEBUG-режиме логируются:
  - Этапы обработки запроса
  - Время выполнения каждого этапа
  - Детали кэширования
  - Вывод CFR (при декомпиляции)
- [ ] По умолчанию DEBUG выключен

## Пример лога в DEBUG-режиме

```
2026-03-27T01:00:00.000Z | DEBUG | Получен запрос: {"method":"get_class_outline",...}
2026-03-27T01:00:00.001Z | DEBUG | Проверка кэша: hit
2026-03-27T01:00:00.002Z | DEBUG | Чтение файла из кэша: /tmp/cfr-decompiled/...
2026-03-27T01:00:00.005Z | get_class_outline | SUCCESS | 5ms | arguments={...}
```
