## Описание

При отсутствии класса в локальном Maven-репозитории предлагать пользователю Maven-координаты для добавления зависимости.

**Проблема:** Сейчас при поиске несуществующего класса возвращается:
```
KafkaTemplate.class не найден в JAR-файлах в /home/user/.m2/repository.
```
Пользователь не знает, какую зависимость добавить.

## Критерии приёмки

- [ ] Ведётся база популярных классов → Maven координат
- [ ] При отсутствии класса предлагается dependency
- [ ] Для классов Spring предлагаются актуальные версии

## Пример

**Вход:**
```json
{"class_name": "KafkaTemplate"}
```

**Выход:**
```
KafkaTemplate.class не найден в локальном Maven-репозитории.

Рекомендуемая зависимость:
  <dependency>
    <groupId>org.springframework.kafka</groupId>
    <artifactId>spring-kafka</artifactId>
    <version>3.0.0</version>
  </dependency>
```
