## Описание

Требуется реализовать тестовый эмулятор MCP-клиента для вызова инструментов MCP-сервера в обычном (однопоточном) режиме.

**Контекст:**
- MCP-сервер предоставляет инструменты через JSON-RPC 2.0
- Требуется эмулятор клиента для тестирования инструментов
- Существующие тесты используют прямой вызов через транспорт

**Цель:**
- Создать универсальный эмулятор MCP-клиента для тестов
- Реализовать вызов инструментов MCP-сервера
- Поддержать синхронные (обычные) вызовы
