## Описание

Добавить параметр `limit` для ограничения количества выводимых классов.

**Проблема:** Сейчас `list_classes_in_jar` выводит все классы (1200+ строк для spring-core), что избыточно.

## Критерии приёмки

- [ ] Добавлен параметр `limit` (по умолчанию 100)
- [ ] Показывается сообщение, если результат обрезан
- [ ] Сохранена возможность получить все классы (limit=0 или null)

## Пример

**Вход:**
```json
{
  "jar_path": ".../spring-core-6.2.15.jar",
  "limit": 20
}
```

**Выход:**
```
Найдено классов: 1198 в spring-core-6.2.15.jar (показаны первые 20):

  org/springframework/aot/AotDetector.class
  ...

Для просмотра всех классов используйте limit=0 или добавьте фильтр.
```
