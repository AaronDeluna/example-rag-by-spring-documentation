## Описание

Требуется реализовать логирование запросов и ответов плагина GigaCode через WireMock для отладки и анализа взаимодействия.

**Контекст:**
- Плагин GigaCode взаимодействует с сервером через HTTP
- Требуется перехватывать и логировать запросы/ответы
- WireMock позволяет создавать прокси для логирования

**Цель:**
- Настроить WireMock для перехвата запросов GigaCode
- Реализовать логирование запросов и ответов
- Обеспечить возможность анализа логов

## Заметки

### Способы логирования

- **WireMock Proxy** — перехват на уровне HTTP
- **Application Layer** — логирование в коде приложения
- **IDE Transport** — логирование на уровне транспорта IDE

### Конфигурация WireMock

```java
WireMockServer wireMockServer = new WireMockServer(
    options().port(8080)
        .proxyVia("localhost", 8081)
);
```
