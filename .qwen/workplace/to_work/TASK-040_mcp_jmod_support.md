## Описание

Добавить поддержку модулей Java 9+ (JMOD, JIMAGE файлы).

**Проблема:** Сейчас сервер работает только с JAR. Java 9+ использует модули в формате JMOD/JIMAGE.

## Критерии приёмки

- [ ] Поддержка чтения JMOD файлов
- [ ] Поддержка чтения runtime image (JIMAGE)
- [ ] Новый инструмент `list_classes_in_jmod`
- [ ] Новый инструмент `list_classes_in_image`
