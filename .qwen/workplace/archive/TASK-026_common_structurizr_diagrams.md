## Описание

Требуется оценить применимость библиотеки Structurizr для автоматической отрисовки диаграмм архитектуры проекта и создать диаграммы для MCP-серверов.

**Контекст:**
- Structurizr — инструмент для создания диаграмм из кода
- Поддерживает C4-модель (Context, Container, Component, Code)
- Позволяет поддерживать диаграммы в актуальном состоянии

**Цель:**
- Оценить применимость Structurizr к проекту
- Создать диаграммы архитектуры для MCP-серверов
- Интегрировать генерацию диаграмм в сборку

## Заметки

### Уровни диаграмм C4

- **Level 1: System Context** — система и внешние зависимости
- **Level 2: Container** — контейнеры (приложения, БД)
- **Level 3: Component** — компоненты внутри контейнеров
- **Level 4: Code** — классы и методы (опционально)

### Варианты интеграции

- Structurizr on-premises
- Structurizr Cloud
- Генерация в локальный файл
