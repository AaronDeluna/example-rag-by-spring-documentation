### Рабочее пространство

Единое рабочее пространство `.qwen/workplace/` используется для всех модулей:
- Задачи создаются в `.qwen/workplace/to_work/`
- Выполненные задачи перемещаются в `.qwen/workplace/archive/`
- Индекс задач: `.qwen/workplace/TASK_INDEX.md`
- Правила проекта: `.qwen/workplace/PROJECT_RULES.md`
