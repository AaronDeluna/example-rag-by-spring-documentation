# Задача: Логирование вызовов инструментов MCP-сервера

## Описание

Добавить возможность логирования всех вызовов инструментов MCP-сервера в текстовый файл `jar-unpacker.log`.

## Требования

### Основные

1. **Файл лога**: `jar-unpacker.log` в рабочей директории проекта
2. **Формат записи**:
   - Дата и время вызова (ISO 8601)
   - Имя вызванного инструмента
   - Параметры вызова (arguments)
   - Результат выполнения (успех/ошибка)
   - Время выполнения (в миллисекундах)

### Пример формата лога

```
2026-03-26T10:15:30.123Z | find_class_in_m2 | {"class_name": "com.example.MyClass"} | SUCCESS | 245ms
2026-03-26T10:15:31.456Z | get_class_outline | {"jar_path": "...", "class_fqn": "..."} | SUCCESS | 89ms
2026-03-26T10:15:32.789Z | get_method_source | {"jar_path": "...", "class_fqn": "...", "method_name": "..."} | ERROR: Method not found | 12ms
```

### Детали реализации

1. **Логгер**: Использовать `java.util.logging` (без внешних зависимостей)
2. **Поток**: Асинхронная запись в файл (не блокировать основной поток MCP)
3. **Ротация**: При достижении 10 МБ — переименовывать в `jar-unpacker.log.1`
4. **Конфигурация**:
   - Путь к логу: `./jar-unpacker.log` (рабочая директория)
   - Максимальный размер: 10 МБ
   - Количество архивных файлов: 3 (`.log.1`, `.log.2`, `.log.3`)

## Изменения в коде

### Server.java

1. Добавить статическое поле `Logger` в начало класса:
```java
private static final Logger logger = Logger.getLogger("JarUnpacker");
```

2. Инициализировать логгер при старте сервера:
   - FileHandler с паттерном ротации
   - Форматтер для однострочного вывода
   - Уровень логирования: INFO

3. Обернуть вызовы инструментов в `handleCallTool()`:
```java
long startTime = System.currentTimeMillis();
try {
    // вызов инструмента
    logger.info(String.format("%s | SUCCESS | %dms", name, elapsed));
} catch (Exception e) {
    logger.warning(String.format("%s | ERROR: %s | %dms", name, e.getMessage(), elapsed));
}
```

## Тестирование

1. Запустить MCP-сервер
2. Вызвать все 4 инструмента через `test_all_tools.py`
3. Проверить создание файла `jar-unpacker.log`
4. Проверить формат записей
5. Проверить запись ошибок (невалидные параметры)

## Критерии приёмки

- [ ] Файл `jar-unpacker.log` создаётся при первом вызове инструмента
- [ ] Каждая запись содержит: timestamp, инструмент, параметры, статус, время
- [ ] Логи не блокируют работу MCP-сервера
- [ ] Ротация файлов работает корректно
- [ ] Все юнит-тесты проходят
