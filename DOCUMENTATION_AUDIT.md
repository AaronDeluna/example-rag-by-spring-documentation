## 🎯 Рекомендуемая структура документации

### Принцип единственного источника истины (Single Source of Truth)

Каждый тип информации должен быть описан **только в одном месте**. Остальные файлы должны содержать **ссылки** на этот источник.

```
example-rag-by-spring-documentation/
├── README.md                    # ← ЕДИНЫЙ источник: обзор модулей, таблицы, сравнения
├── CHEATSHEET.md                # ← ЕДИНЫЙ источник: команды сборки/запуска (кратко)
├── QWEN.md                      # ← ЕДИНЫЙ источник: настройка Qwen Code, TDD, задачи
├── README-VADIM.md              # → УДАЛИТЬ (дублирует README.md)
├── .qwen/workplace/
│   ├── PROJECT_RULES.md         # ← ЕДИНЫЙ источник: правила XP/TDD, конвенции
│   └── ...
└── mcp-server-jar-unpacker/
    └── QWEN.md                  # ← ЕДИНЫЙ источник: документация модуля
```
